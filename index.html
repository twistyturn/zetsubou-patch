Zetsubou Patch for Danganronpa on Steam

Play the Steam version of Danganronpa: Trigger Happy Havoc with Project Zetsubou's 2013 fan translation: Super Duper High School students, the ElectroiD, Ammunition and all.

On your phone right now? Open this page on the computer or Steam Deck where you play, and download it there. You can read the steps here first.

Pick the one that matches where you play. The steps for both are below.

The download contains only translated text and lettering. It never includes the game itself, so you need your own copy on Steam.

How to install on a Windows PC

7 small steps

  1. Download the patch

    Click Download for Windows PC. The file lands in your Downloads folder.

  2. Unpack it

    Right-click the zip file, choose Extract All..., then click Extract.

    This step matters: the installer can't run from inside the zip.

  3. Open the new folder and double-click the installer

    The folder is called Zetsubou Patch for Danganronpa (Windows). Inside, double-click Install Zetsubou Patch.

    If the game is open, close it first.

  4. Tell Windows it's okay

    Windows will show a warning like this. That's normal for downloads; click More info, then Run anyway.

    If you get a smaller box with a Run button instead, click Run.

  5. Wait a few minutes

    A small window with a progress bar appears. Let it work; you don't need to do anything.

  6. See "Done!" and click OK

    When the message says Done!, click OK. That's the whole installation.

  7. Start the game from Steam

    Open Steam and press Play, just like always.

How to install on a Steam Deck

6 small steps

  1. Switch to Desktop Mode

    Press the STEAM button, then choose Power, then Switch to Desktop.

  2. Download the patch on the Deck

    Open this page in the Deck's web browser and click Download for Steam Deck. The file lands in Downloads.

  3. Unpack it

    Open the file manager (the blue folder icon in the taskbar) and go to Downloads. Right-click the zip file and choose Extract, then Extract archive here.

    No mouse? Pressing the left trigger works as a right-click.

  4. Open the new folder and double-click the installer

    The folder is called Zetsubou Patch for Danganronpa. Inside, double-click Install Zetsubou Patch. If the Deck asks whether to run it, choose Execute or Continue.

    If it opens as a page of text instead, the "README" file in the same folder shows the fix (ticking "Is executable").

  5. Wait for "Done!"

    A window shows the progress. It takes a few minutes. When it says Done!, close the window.

  6. Go back and play

    Double-click Return to Gaming Mode on the desktop, then start Danganronpa as usual.

One tip: set the voices to Japanese

In the game's Options, switch the voices to Japanese. Project Zetsubou translated from the Japanese, so the words on screen match what you hear.

The English voices were recorded for the official translation, so with them the spoken lines often won't match the text.

Changed your mind?

Open the patch folder again and double-click Restore Original Game. The installer kept a copy of the original and puts it back. Your saves are fine either way.

Steam can undo it too: right-click the game in your Library, then Properties → Installed Files → Verify integrity of game files.

If something goes wrong

You can't break your game with this. The installer checks everything before it changes anything. If a check fails, your game is left exactly as it was, and the message tells you what to do.

It says "Danganronpa is running".
Close the game, then double-click the installer again.
It says the game "isn't the official Steam version".
Another mod may be installed. In Steam, right-click the game, then Properties → Installed Files → Verify integrity of game files. When Steam has finished, run the installer again.
It says "Not enough free space".
Free up about 1.5 GB on the drive where the game is installed, then try again.
Nothing happens when I double-click the installer.
Make sure you unpacked the zip first (step 2 on Windows, step 3 on Steam Deck). If it still won't start, the "README" file in the patch folder has one more thing to try.

More about the patch

What does the patch change?
  • The translation is Project Zetsubou's, carried over line by line, with a small number of fixes: slurs and stereotypes the translation added that aren't in the Japanese, a few misreadings, and a few lost puns.
  • Names and terms follow Zetsubou everywhere: Kyouko, Touko, Oowada, Oogami, Celes, Genocider Shou, Super Duper High School, ElectroiD, Ammunition, Epiphany Anagram, Machinegun Talk Battle, Climax Logic.
  • The school keeps its official name, Hope's Peak Academy. Project Zetsubou used the Japanese name, Kibougamine.
  • On-screen lettering was redone to match: chapter titles, student intro cards, name tags, the School Rules pages, door nameplates and more. The new lettering is painted onto your own copy of the game when you install.
  • Epiphany Anagram puzzles are adjusted so Zetsubou's answers fit.
  • The opening movie that plays every time the game starts is cut to about three seconds, because it can't be skipped with a controller on the Steam Deck.
  • Parts the Steam version added (School Mode and a few extras) keep the official English text, with names and terms matched.
  • Button instructions keep the official text, so the prompts are always right for your controller or keyboard.
