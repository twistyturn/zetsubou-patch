# Zetsubou Patch for Danganronpa: Trigger Happy Havoc (Steam)

This patch puts **Project Zetsubou's 2013 fan translation** into the Steam
version of *Danganronpa: Trigger Happy Havoc*, on a Windows PC or a Steam Deck.

## ➡️ Download and instructions: https://twistyturn.github.io/zetsubou-patch/

The page above has the download button and illustrated step-by-step
instructions. It takes about five minutes.

Direct downloads, if you already know what to do:

- **Windows PC:** [Zetsubou-Patch-DR1-Windows-v1.0.zip](https://twistyturn.github.io/zetsubou-patch/downloads/Zetsubou-Patch-DR1-Windows-v1.0.zip)
- **Steam Deck:** [Zetsubou-Patch-DR1-Deck-v1.0.zip](https://twistyturn.github.io/zetsubou-patch/downloads/Zetsubou-Patch-DR1-Deck-v1.0.zip)

You need to own the game on Steam. The patch contains only translated text and
lettering, never the game's own files.
